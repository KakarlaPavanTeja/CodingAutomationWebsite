# Problem: Echo the Number
# Type: standard
# Question Type: nonfunction
# Scenario Level: none
# Echo the Number

Read a single integer from standard input and print it back on its own line.

## Input Format

A single line containing one integer n.

## Output Format

A single line containing n, followed by a newline.

## Constraints

- −10^9 ≤ n ≤ 10^9

## Example 1

**Input:**
```
42
```

**Output:**
```
42
```

**Explanation:** The input is 42, so the output is 42.

## Example 2

**Input:**
```
-1000000000
```

**Output:**
```
-1000000000
```

**Explanation:** Negative values at the lower bound of the constraint are echoed unchanged.
