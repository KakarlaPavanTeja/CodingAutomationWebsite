Coding Automation · Local Setup

Run the app on your machine

Pick your OS and run the steps top to bottom. The app connects to the team's shared cloud database — no local database, no Docker.

The script installs Node & Python for you. You just need git — no Docker, no local database.
  1. Clone the project
    git clone https://github.com/KakarlaPavanTeja/CodingAutomationWebsite.git
cd CodingAutomationWebsite
  2. Add the secrets — paste the 4 values from your team lead
    cp scripts/team-secrets.env.example scripts/team-secrets.env
nano scripts/team-secrets.env   # OPENROUTER_API_KEY, ADMIN_SECRET_KEY, CRON_SECRET, DATABASE_URL
  3. Run setup
    chmod +x scripts/setup-local.sh
./scripts/setup-local.sh --install-system-deps --yes
  4. Start the app
    npm run dev

Then open the app

Go to localhost:5001/signup and create your account.

Sign up as admin using the ADMIN_SECRET_KEY — admin accounts work right away, no approval needed.

Everyone shares the same cloud database, so the users and problems you see match your teammates'.

What you can open

/problems — browse & manage problems · /pipeline — run the generation pipeline · /outputs — generated files · /settings — your account · /guide — usage guide · /admin — users & LLM cost (admins only).

All backed by the shared cloud database — the same data as your teammates.

If something goes wrong

“DATABASE_URL missing in team-secrets.env”
You didn't fill in the shared database URL. Open scripts/team-secrets.env and paste the DATABASE_URL your team lead gave you, then re-run setup.
Can't connect to the database
Make sure the DATABASE_URL is copied exactly and ends with ?sslmode=require. Check your internet connection — the database lives in the cloud.
Dev server shows “Ready” but the browser spins
The first page load compiles for 1–2 min. Wait, or use npm run build && npm run start for faster loads.
